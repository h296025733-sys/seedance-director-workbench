# Seedance 执行层交接

任务需要 Seedance 模型/模式、素材上传、`@` 绑定、分段或提示词时完整读取。执行参数易变，先读工作区 `knowledge/Seedance当前能力与限制.md`、`Seedance来源索引.md`、`Seedance界面模式决策表.md`、`Seedance素材限制表.json`、`Seedance待实测功能.md` 和 `Seedance素材职责矩阵.md`，再调用 `seedance-ui-planner` 与 `seedance-director`。

## 状态词

独立记录：`UI_VISIBLE`、`UI_SELECTABLE`、`OFFICIAL_DOCUMENTED`、`ACCOUNT_VERIFIED`、`GENERATION_TESTED`、`CURRENTLY_RECOMMENDED`。界面看见不等于可选，可选不等于生成有效，一次生成不等于稳定成功。

## 模式选择

- 混合图片/视频/音频、`@` 职责、参考结构/动作/运镜/声音或 HYBRID：全方位/全能参考优先候选。
- 严格首尾状态、A→B 转换或尾帧稳定：首尾帧候选，写明中间路径与不变项。
- 多影格/多帧只有在当前账号可选且行为验证后正式推荐；否则用多张职责清楚的图片和分段时间描述。
- 主体参考先验证入口、锁定对象、授权与审核，不能按名字推断功能。
- 无参考的原创概念可用文本生成能力，具体入口仍以当前界面为准。
- 延长、编辑、融合先确认是独立模式还是全方位参考用法，并确认时长语义。

## 素材职责与上传顺序

只上传正式提示词会使用的素材。每项记录：

| 上传序号 | 本地绝对路径 | 官网显示名 | 类型 | 核心职责 | 次要职责 | 明确不参考 | 时段 | 优先级 |
|---:|---|---|---|---|---|---|---|---|
| 1 |  |  | 图片/视频/音频 |  |  |  |  |  |

默认冲突优先级：产品原图负责产品真实外观；身份图负责人物是谁；动作图/视频负责怎么动；场景图负责在哪里和视觉氛围；分镜负责镜头顺序与关键构图；真实已验收尾帧负责续接起点。

上传顺序确定后再写 `@图片1/@视频1/@音频1`。逐项核对类型与编号，官网重排后必须同步改提示词。参考视频明确区分动作、运镜、节奏、转场和声音，并列出不参考的人物、产品、品牌、字幕、背景或遮罩。

## Seedance 提示词结构

导演完整版按以下顺序：

1. 输出规格、主目标和唯一主痛点；
2. 主体、产品与连续性锚点；
3. 每个素材的职责与不参考项；
4. 分时段动作、镜头、构图与产品证明；
5. 台词、字幕、音乐、音效与同步点；
6. 场景、光线、色彩和风格；
7. 产品、人物、版权、合规和画面禁止项；
8. 尾帧状态及稳定时长。

直接粘贴版保留所有硬约束与时间码，删除解释、评分、重复形容词、相互冲突的运镜和模型无法执行的事件密度。`@` 编号必须与执行卡一致。

## 分段与有限次数

超出当前可用时长或事件过密时分段。第一次优先生成 4–5 秒高风险段，验证钩子、人物/产品一致性、关键证明和可续接状态；用户授权消费额度后才执行。首段未通过硬门槛不得做第二段。续接以真实已验收成片和精确尾帧为最高连续性证据。

## 权限与真实性

默认只规划，不上传、不登录、不点击生成、不消费积分。参考视频、衍生分镜、真人身份和品牌资产上传前确认权利与授权。AI 虚构成年角色说明只陈述事实，不保证平台审核。
