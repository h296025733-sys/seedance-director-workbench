# 创意方向与评分

在详细分镜前完整读取。目标不是机械输出“痛点型/反差型/共鸣型”标签，而是提出三条在注意力入口、说服路径或证明方式上真正不同、又都由产品事实承接的方向。

## 生成三个方向

每个方向至少写：

1. 方向名和一句话核心创意；
2. 对应用户、购买阶段和唯一主痛点；
3. 0–1 秒停止滑动刺激与 0–3 秒钩子；
4. 产品何时、为何介入；
5. 核心证明方式；
6. 情绪回报与 CTA；
7. 与参考机制的关系，以及重新创作了什么；
8. 所需人物、场景、产品和证明素材；
9. 最大合规、生成与素材风险。

差异必须能落到至少两个主要变量：例如方向 A 用即时失败场景 + 过程演示，方向 B 用反常结果 + 对照证明，方向 C 用身份代入 + 细节证据。只换标题、台词同义词或服装不算不同方向。

## 统一评分量表

每项 1–5 分，附一条基于当前证据的理由：

| 维度 | 5 分含义 |
|---|---|
| 痛点强度 | 具体、高损失且与材料/研究一致 |
| 前 3 秒清晰度 | 无背景解释也能理解问题或承诺 |
| 产品中心度 | 产品是不可替代的解决机制 |
| 视觉证明能力 | 核心卖点可用真实画面直接证明 |
| 新鲜度 | 表达不同于参考片独特资产和品类陈词滥调 |
| 用户代入感 | 人物、时刻与目标用户任务高度一致 |
| 信任建立 | 有过程、细节、限制或可靠来源降低怀疑 |
| 转化潜力 | 说服链完整，CTA 匹配购买阶段 |
| Seedance 可控性 | 主体、动作、镜头和时长约束清楚 |
| 素材可获得性 | 必需素材已有或低成本可验证地产生 |
| 合规安全性 | 宣称有证据且不依赖高风险表达 |
| 有限次数成功概率 | 首次即可验证核心风险，事件密度合理 |

“合规风险”作为负向概念易混淆，评分表统一写“合规安全性”：5 分风险低、1 分风险高。不得给出虚假精度；分数是导演决策标尺，不是播放、转化或生成成功率预测。

## 推荐规则

- 任何核心宣称未通过证据门禁的方向不得推荐，即使总分高。
- 产品中心度或视觉证明能力低于 3 分，先重做，不用平均分掩盖。
- 有限生成次数下，优先能在首个 4–5 秒验证最大风险的方案。
- 分数接近时，优先证据更强、素材冲突更少、可回滚性更高的方向。
- 若三条方向都依赖同一未经证实卖点，停止并补证或换痛点。

## A/B 设计

主方案通过后才设计 A/B。一次只改变钩子文案、第一镜构图、痛点强度、证明方式、人物类型或 CTA 中的一项；人物、场景、节奏、卖点等其他变量保持一致。写出假设、唯一变化、固定项、观察指标、样本/窗口和停止条件。没有真实数据只报告测试设计。
