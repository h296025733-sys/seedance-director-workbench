# 脚本、镜头与标准交付

主创意选定后完整读取。正式策划按以下顺序交付；某项确实不适用时保留标题并说明原因，不静默省略。

## 标准交付顺序

1. 任务定义与 `REFERENCE / ORIGINAL / HYBRID`。
2. 目标用户与购买阶段。
3. 产品事实与宣称清单。
4. 参考视频事实时间轴；无参考片时写“不适用”。
5. 爆款/注意力/转化机制诊断及 `FACT / INFERENCE / UNKNOWN`。
6. 可迁移机制与不可复制内容。
7. 唯一核心痛点。
8. 欲望、恐惧、顾虑和反对理由。
9. 三个差异化创意方向及统一评分。
10. 推荐主方案和选择理由。
11. 一句话核心创意。
12. 0–1 秒刺激与前 3 秒钩子。
13. 完整原创说服链。
14. 分秒级脚本。
15. 完整镜头表。
16. 人物与场景设计。
17. 身份图、场景图、产品图和分镜图需求。
18. 每张图片的生成提示词。
19. 素材职责、冲突与优先级。
20. 《Seedance官网执行卡》：模型、模式、比例、分辨率、时长和声音。
21. 实际上传顺序。
22. 与上传顺序完全一致的 `@` 素材绑定。
23. 导演完整版 Seedance 提示词。
24. 可直接粘贴版提示词。
25. 生成前审核表。
26. 生成后验收标准。
27. 有限次数下第一次与第二次分别验证什么。
28. 后续单变量 A/B 测试建议。

正式 Seedance 结果必须先给执行卡，再给导演完整版与直接粘贴版。

## 分秒级脚本

用可执行时间范围，不写“快速展示一些场景”。每段记录：

| 时间 | 叙事任务 | 画面与动作 | 台词/字幕 | 声音 | 产品职责 | 心理作用 | 证据/状态 |
|---|---|---|---|---|---|---|---|
| 0.0–1.0 秒 | 停止滑动 |  |  |  |  |  |  |
| 1.0–3.0 秒 | 建立钩子 |  |  |  |  |  |  |
| 后续 | 证明/反对/回报 |  |  |  |  |  |  |

同一时间段只安排模型可以辨认的主要动作。时长不足就删事件或分段，不用抽象形容词掩盖过载。

## 镜头表

每镜必须包含：

| 时间 | 画面 | 人物 | 动作 | 景别 | 机位 | 运镜 | 台词/字幕 | 音效/音乐 | 产品展示职责 | 心理作用 |
|---|---|---|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |  |  |  |  |

另记转场、光线、色彩、连续性和禁止项。不要从单帧武断写精确焦段或三维机位；不确定项写成待测试假设。

## 图片需求与提示词

每张图单列：

- 文件建议名和核心职责；
- 画面主体、人数、产品、构图、景别、角度、动作、场景、光线、风格、比例；
- 必须锁定的身份/产品细节；
- 明确不出现的文字、Logo、人物、肢体错误和职责冲突；
- 使用时间段与是否上传；
- 生成后人工验收项。

产品图、包装图或人物图已有时优先使用可追溯原件；AI 图不得伪造产品属性、实验、证言或认证。

## 声音与字幕

为每个声音元素写职责：语音负责什么信息，音效强调哪个动作，音乐如何建立和释放张力。避免音乐、人声和音效同时争抢核心信息。关键字幕优先后期叠加；视频模型生成的长文字不作为可控交付。

## CTA

CTA 与购买阶段匹配：未意识/问题意识阶段可提示继续了解或收藏；方案/产品意识阶段可引导查看规格、比较或咨询；临近购买阶段才使用合规的购买行动。没有真实优惠、库存或时限，不制造稀缺。

## 有限次数计划

- 第一次验证最大的不确定性：通常是 0–3 秒钩子、产品证明、人物/产品一致性和关键交互。
- 第二次只在首轮通过硬门槛后扩展、续接或验证一个次要变量。
- 为每次写通过标准、阻断失败和失败时只改哪一层。
- 本地策划无法证明实际生成或发布表现；等待真实结果后再验收和更新经验。
