# 提示词模板

以下是结构模板，不是无需检查的固定答案。把方括号替换为真实内容；`@` 编号必须与界面上传顺序一致。

## 第一段：5 秒高风险验证

```text
生成一条[5秒]、[9:16竖屏]、[720P]、[目标画风/真实质感]的[单镜头或按参考剪辑]视频。

主体与场景：
@图片1 只负责两名AI原创、虚构成年人物的身份、脸、发型、体型、服装和配色。全片始终是这两个人；不得使用或还原动作参考中的真人身份、脸、肤色、发型或服装。
@图片2 只负责[场景布局、材质、灯光、色调]，不得新增人物、品牌、文字或水印。
@图片3 只负责0至5秒关键动作状态、人物相对站位和构图节奏；若局部细节与@图片1冲突，人物身份以@图片1为准。
@视频1 只负责0至5秒的动作顺序、身体轨迹、关键手势、人物相对位置、运镜、剪辑点、节奏和原有声音。绝不参考其中人物身份、脸、肤色、发型、服装、背景、品牌、字幕和水印。视频中的黑色椭圆仅是隐私遮挡，绝不是角色造型；成片不得出现黑块、马赛克、面罩或任何遮挡。

时间轴：
0.00–[x.xx]秒：[可观察的起始构图、人物位置、手势、目光、镜头运动]。
[x.xx]–[y.yy]秒：[动作轨迹与关键接触，说明左右手和前后关系]。
[y.yy]–5.00秒：[动作完成状态和稳定尾帧，为下一段续接保留清楚姿态]。

摄影与质量：
[机位高度、景别、镜头运动、焦段倾向、光线、材质、画风]。人物脸和服装在所有帧保持一致，双手结构正常，动作自然，无多余人物，无身份漂移，无闪烁，无画风跳变。

禁止项：
不得还原参考视频真人；不得把真人仅改衣服或改色；不得生成第三人；不得复制黑色遮挡、马赛克、水印、字幕、Logo；不得改变人物数量、动作顺序和关键手势；不得出现多余手指、融合肢体或人物穿插。
```

## 第二段：从精确尾帧续接

```text
生成一条[剩余时长]、[9:16竖屏]、[720P]、与上一段完全连续的[目标画风]视频。

连续性最高优先级：
@图片4 是已验收第一段的精确最后一帧。新视频第0帧必须与它在人物身份、姿态、手位、服装、构图、机位、光线、场景和画风上无跳变，并从该动作状态立即继续。
@视频2 是已验收第一段成片，只参考其中两名目标人物的一致外观、场景、画风、运动质感、镜头语言和结尾节奏。

固定主体与场景：
@图片1 负责同一两名AI原创、虚构成年人物身份；全片不得换脸、换发型、换服装或改变体型。
@图片2 负责同一场景、灯光和色调。
@图片3 只负责第二段后续关键动作状态。若它的第一格与@图片4冲突，忽略第一格冲突部分，以@图片4为绝对起点。
@视频3 只负责[5秒至结尾]动作顺序、身体轨迹、关键手势、人物相对位置、运镜、剪辑点、节奏和声音；不参考其中真人身份、脸、肤色、服装、背景、品牌、字幕或水印。黑色椭圆仅为隐私遮挡，成片绝不出现。

时间轴（相对于本段0秒）：
0.00–[x.xx]秒：从@图片4动作状态无缝继续，[明确动作轨迹]。
[x.xx]–[y.yy]秒：[明确双方动作和关键接触]。
[y.yy]–[结束]秒：[结尾构图、表情、镜头和声音落点]。

禁止项：
不得重置站位、回到分镜第一格、重复第一段动作或硬切开场；不得出现身份漂移、服装变化、场景变化、黑块、马赛克、第三人、肢体融合、额外手指、镜头无故跳变。
```

## 给 GPT 网页生成身份图

```text
请生成一张[9:16/方形]高分辨率人物设定参考图，用于后续视频生成，不要添加文字、分格线、水印或品牌。

两名AI原创、虚构、成年动漫人物，一男一女，绝非任何现实人物或现有影视/动漫角色。
男性：[肤色、脸型、发型、眼睛、体型、服装、主色、配饰]。
女性：[肤色、脸型、发型、眼睛、体型、服装、主色、配饰]。
两人全身或至少膝盖以上，正面略微三分之二角度，自然站立，脸部清楚，双手可见且结构正确，身高比例明确。背景纯净、弱化，不承担场景信息。角色设计在后续所有图片中必须保持完全一致。
```

## 给 GPT 网页生成场景图

```text
请生成一张[9:16]高分辨率纯场景参考图，用于视频背景锁定。场景为[详细空间]，包含[布局、材质、灯光、色调、关键物件]。画面中没有人物、脸、手、文字、Logo、水印或品牌；镜头高度和透视适合两名人物进行[动作类型]。保持[目标风格]，细节清楚，不要景深糊掉关键空间结构。
```

## 给 GPT 网页生成四格分镜

```text
使用我提供的两名人物身份图，生成一张2×2四格分镜图。四格中的人物脸、发型、体型、服装、配色和身高关系必须一致；背景始终是同一[场景]。不要添加文字、对白框、水印或多余人物。每格边界清楚，9:16构图语义。

第1格 [时间]：[人物站位、左右手、表情、景别、机位]。
第2格 [时间]：[动作轨迹和关键手势]。
第3格 [时间]：[互动/接触状态]。
第4格 [时间]：[结束状态和构图]。

尤其检查：左右手不能颠倒，手指正常，人物不能融合，动作顺序不能互换。分镜只表达关键状态，不擅自增加镜头切换。
```

## 诊断式修订句

- 人物未替换：`动作参考中的人物身份全部无效；必须从@图片1重新构建两名目标人物的脸、肤色、发型、体型和服装，禁止保留原人物后只改衣服或画风。`
- 黑块被复制：`黑色椭圆是后期隐私遮挡，不属于物体或服饰；依据@图片1完整重建遮挡区域内的脸，任何帧都不得出现黑块/面罩/马赛克。`
- 分镜覆盖尾帧：`@图片4的真实尾帧优先级高于@图片3第一格；忽略两者冲突处，第一帧必须匹配@图片4。`
- 动作弱化：`动作幅度、手部轨迹、人物间距离和关键接触以@视频1为准，不得用静态站立、挥手或随机表演代替。`

不要同时堆叠所有修订句。先根据失败证据选最主要的 1–2 项，避免提示词内部权重冲突。
