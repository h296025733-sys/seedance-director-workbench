# 生成前后验证门槛

## 证据等级

- `SOURCE_INSPECTION`：只读文件/代码/网页。
- `STATIC_CHECK`：语法、格式、清单、哈希或元数据检查。
- `ISOLATED_SELF_TEST`：脚本用合成或小样本执行。
- `LOCAL_REAL_MEDIA`：对用户真实视频的本地执行。
- `ACCOUNT_UPLOAD`：用户当前账号在指定入口上传通过。
- `ACCOUNT_GENERATION`：指定模型、参数和素材真实生成。
- `USER_ACCEPTED`：用户观看后确认结果满足目标。

报告时必须给出具体等级。较低等级不能冒充较高等级。

## Gate A：原视频可理解

全部满足才通过：

- [ ] 文件可读，SHA-256 与元数据已记录。
- [ ] 时长、帧率、尺寸、旋转、音轨明确。
- [ ] 全片和关键动作接触表已人工查看。
- [ ] 镜头边界、动作顺序、关键接触、声音落点有时间戳。
- [ ] 自动分析的明显误切/漏检已人工修正。

## Gate B：替换边界明确

- [ ] `HARD_LOCK/SOFT_LOCK/REPLACE/VARY/DO_NOT_REFERENCE` 已写。
- [ ] 原人物身份、脸、肤色、服装等是否保留没有歧义。
- [ ] 品牌、字幕、水印和现有角色特征已排除或获得授权。
- [ ] 人物数量、年龄设定和用户要求一致。

## Gate C：参考素材可用

### 身份图

- [ ] 是目标人物，不是原视频人物。
- [ ] 同一角色在所有图中脸、发型、体型、服装一致。
- [ ] 人物清晰，手部/肢体没有明显错误。
- [ ] 没有意外文字、水印、品牌或第三人。

### 场景图

- [ ] 空间结构和目标机位兼容。
- [ ] 没有与身份图冲突的人物。
- [ ] 光线、色彩、画风足够明确。

### 分镜图

- [ ] 每格可单独看懂。
- [ ] 时间顺序、人物站位、左右手、关键手势正确。
- [ ] 人物跨格一致，无新增人物或错误动作。
- [ ] 不把单镜头动作误画成强制四次剪辑。

### 去身份动作视频

- [ ] 时长、FPS、尺寸、音轨与原片段一致或差异有解释。
- [ ] 遮挡紧贴脸部特征，没有大面积盖住手/手臂/身体。
- [ ] 主脸、侧脸、快速转头和背景小脸都逐帧或接触表检查。
- [ ] 后处理检测统计已生成；人工复核也通过。
- [ ] 黑色遮挡不会被误认为目标造型，提示词有明确禁止项。

任何一项失败，素材不能上传。参数或脚本成功退出不能替代视觉审核。

## Gate D：平台执行卡一致

- [ ] 当前截图中模型/入口可见且可选择；若仅可见，标记 `UI_VISIBLE`。
- [ ] 比例、分辨率、时长、数量与预算一致。
- [ ] 上传顺序和提示词 `@` 编号逐项一致。
- [ ] 每个素材只有一个核心职责并写了不参考项。
- [ ] 有限次数下，第一段确实覆盖最高风险。
- [ ] 已保存完整提示词与直接粘贴版。
- [ ] 原生上传/审核错误已解决；未解决时禁止生成。

## Gate E：第一段生成验收

以下任何一项为阻断失败：

- 原人物仍存在，或只改了衣服/画风而没有换身份。
- 人物数量、性别/成年设定、核心服装或发型错误。
- 钩子或关键动作缺失、顺序颠倒、关键接触错误。
- 场景/画风与目标明显不符。
- 黑块、马赛克、原字幕、水印、品牌或第三人被复制。
- 明显肢体融合、额外手指、脸部崩坏、穿模或严重闪烁。
- 末尾状态不稳定，无法续接。

通过时仍需写明轻微偏差，不能只写“通过”。提取精确尾帧并计算哈希。

## Gate F：第二段连续性验收

- [ ] 第0帧与第一段精确尾帧无明显跳变。
- [ ] 同一人物身份、服装、体型、场景和画风保持。
- [ ] 没有回到分镜第一格或重复上一段动作。
- [ ] 后续动作顺序与原参考剩余段一致。
- [ ] 拼接点音频、运动方向、机位和光线自然。

## 最终报告格式

```text
结论：[可生成 / 暂停修复 / 首段通过可续接 / 失败需重做]
实际验证层级：[列出]
已通过：[具体项目]
未通过：[具体项目]
未测试：[平台上传/实际生成/用户主观验收等]
剩余不确定性：[具体]
推荐下一步：[只给一个最稳动作]
```

不要使用“保证成功”“完美复刻”“全部验证通过”，除非明确限定范围且该范围内所有材料路径都实际执行成功。
