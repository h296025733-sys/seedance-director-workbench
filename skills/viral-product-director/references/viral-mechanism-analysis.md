# 爆款机制分析

在存在参考视频、竞品视频或用户要求解释“为什么有效”时完整读取。先消费 `watch-video` 证据包和 `viral-video-breakdown`，再做心理与转化推断。

## 真值分层

| 层级 | 可写内容 | 写法 |
|---|---|---|
| `FACT` | 时间、画面、台词、景别、剪辑、字幕、产品露出、证明动作、声音 | 绑定时间戳和证据路径 |
| `INFERENCE` | 好奇、损失厌恶、身份代入、视觉反差、可信度、互动动机 | 写支持事实、反证和可信度 |
| `UNKNOWN` | 投流、账号权重、受众定向、完播、复播、点击、转化、销量、评论治理 | 明确视频本身无法知道 |

不得把 `INFERENCE` 改写成已证实因果。只有用户提供可靠的发布或投放数据，才能检验机制与表现的关系。

| 0–0.5 秒 |  |  |  |  |  |  |  |
| 0.5–1 秒 |  |  |  |  |  |  |  |
| 1–2 秒 |  |  |  |  |  |  |  |
| 2–3 秒 |  |  |  |  |  |  |  |
| 后续逐镜 |  |  |  |  |  |  |  |

“直接功能”只写可观察的结构作用，如暴露问题、遮延答案、演示变化、给出 CTA；不要先写心理结论。

## 机制诊断清单

1. **0–1 秒停止滑动**：视觉突变、异常构图、声音冲击、直视镜头、危险/欲望线索或高信息差是什么？若没有明显刺激，如实写无。
2. **0–3 秒钩子**：观众立即知道“与我有关”的哪件事？承诺、问题或未完成信息是什么？
3. **观看前状态**：目标观众当下可能正在忍受、担心、寻找或比较什么？这是推断，需要受众证据。
4. **痛点层次**：功能、情绪、身份/社交三层中哪一层被直接表现，哪一层只是推断？
5. **损失与即时欲望**：观众害怕继续失去什么，又希望马上得到什么？
6. **好奇缺口**：何时建立、用什么延迟答案、何时偿还，是否兑现了开头承诺？
7. **模式打断**：冲突、反差、意外、悬念或节奏变化发生在哪里？
8. **产品介入**：首次出现时间、是否与问题有因果连接、是否真正执行解决动作。
9. **证明结构**：现场演示、前后对比、细节、过程、数字、证言、专业解释、失败/成功对照中的哪种真实存在？
10. **注意力维持**：信息密度、镜头长度、动作变化、字幕节奏、音效卡点各自承担什么任务？
11. **信任**：可核查细节、过程透明、限制说明、人物角色或画面证据如何降低怀疑？
12. **互动动机**：评论、收藏、分享可能来自实用性、身份表达、争议、求证、提醒他人或未解问题中的哪种？只写假设。
13. **结尾回报**：情绪回报、价值回报、答案回报和行动推动是否完整？

## 机制与资产分离

逐项分类：

- `TRANSFERABLE_MECHANISM`：如先呈现失败再证明改进、在 2 秒内建立信息差、让产品完成可视化动作。
- `ADAPTABLE_STRUCTURE`：如“问题→试错→证明→结果”，可保留功能但重写内容与镜头。
- `UNIQUE_ASSET`：原作者独特台词、角色关系、标志性表演、镜头组合、品牌、音乐、字幕设计或其他受保护表达。
- `DO_NOT_COPY`：未经授权的真人身份、Logo、水印、专属文案、角色和品牌资产。

## 原创映射表

| 参考机制 | 支持事实 | 触发心理（推断） | 产品能否真实承接 | 新视觉证明 | 保留的结构功能 | 必须重写 | 禁止复制 |
|---|---|---|---|---|---|---|---|
|  |  |  | 是/否/待证 |  |  |  |  |

产品不能真实承接时，删除该机制，不要为了相似而硬套。若有效部分依赖原作者的独特资产，寻找不同表达达成相同心理功能。

## 结论写法

使用“该片观察到……；这些事实支持……的机制假设；但没有发布数据，不能证明它导致了播放或转化”的结构。为关键推断给出 `HIGH / MEDIUM / LOW / UNKNOWN`，其中 `HIGH` 仍只是证据强的推断，不等于因果实验。
